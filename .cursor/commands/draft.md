# /draft

`_draft` にある記事メモを、指定した形式で清書するためのコマンド。

## 使い方

`/draft 記事ファイル`

例: `/draft _draft/配信できない理由（うるさいから）.md`

## 実行ルール

1. 引数のファイルを読み込む。引数が空なら、対象ファイルの指定をユーザーに求める。  
2. 次の質問をユーザーに投げる。  
   - `清書形式を選択してください: 1. 4thaveの記事 2. SNS投稿`  
3. ユーザーの数字入力で分岐する。  
   - `1` の場合: `.claude/post-workflow.md` と `.cursor/rules/editorial-guide.md` に従って、4thave向け記事として清書する。  
   - `2` の場合: `.cursor/rules/editorial-guide.md` の「_draft からSNS投稿向けに清書するWorkflow」に従って清書する。  
4. `2`（SNS投稿）の場合は、さらに次を確認する。  
   - `投稿形式を選択してください: 1. 単ポスト 2. 複数スレッド（未指定なら文字量で自動判定）`  
5. 最終出力の先頭に、採用したWorkflowを明記する。  
   - 例: `採用Workflow: 4thave記事（理由: ユーザー選択 1）`  
   - 例: `採用Workflow: SNS投稿 / 単ポスト（理由: ユーザー選択 2-1）`

## 出力方針

- トーンは必ず `Persona`（さしし）に準拠する。  
- 事実の水増しをしない。元ドラフトの意図を優先する。  
- 必要なら最後に「このまま保存するか」を確認する。
