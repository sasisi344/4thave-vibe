# 4thaveの説明書

## 記事作成について

基本的に当日のファイルネームでジャーナルを残す程度。だからフォルダと週番号で記事を作成する。

@scriptフォルダに「new-note.bat」がある。これを実行すると、contentの該当部分にフォルダがなければ作成し、ファイルは現在の日付で作成する。あとは記事を書いて、AIにtagsとか要約を入れてもらえばいいだけです。

## Agentルール運用（2026-04-27更新）

- これからは Cursor 上のAgentも、ルートの `CLAUDE.md` を基準に動く。
- ルール配置は次の構成に移行済み。
  - `CLAUDE.md`：参照優先順位と全体方針
  - `.cursor/rules/editorial-guide.md`：執筆ルール（SNS分岐Workflow含む）
  - `.claude/post-workflow.md`：清書・公開の実行手順
- 旧 `.agent` のWorkflow/ルールは `.claude` と `.cursor/rules` へ移行済み。

## スラッシュコマンド（ドラフト清書）

- `/draft 記事ファイル` でドラフト清書を開始できる。
- 実行時に次を選ぶ。
  - `1`: 4thaveの記事として清書
  - `2`: SNS投稿として清書
- `2` を選んだ場合は、さらに
  - `1`: 単ポスト
  - `2`: 複数スレッド
  を選んで分岐する。
